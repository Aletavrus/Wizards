Проект маленького школьника

Это будет пошаговая PvP про магов

Есть несколько классов игроков со своими способностями (сейчас способности будут сразу привязаны к конкретному классу)

Есть несколько видов абилок: по клетке конкретной (SpellTargeted), по области (SpellNotTargeted) и Ultimate (супер крутая способность).
Каждый ход или использование способности отнимают "ману", которая восстанавливается частично после каждого раунда.

Сначала планируется сделать ядро игры (структура классов). Потом кастомизировать классы, придумывать способности и пытаться сделать так, чтобы Avalonia не умерла от моих задумок
